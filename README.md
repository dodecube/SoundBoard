# 🎵 SoundBoard

Программа для случайного воспроизведения звуков с настраиваемой вероятностью.

## Как работает

Каждую секунду (интервал настраивается) генерируется случайное число. Если оно попадает в указанную вероятность — воспроизводится случайный звук из включённых.

**Пример:** вероятность `1 / 100000` → звук воспроизведётся в среднем один раз на 100 000 проверок.

## Установка

```bash
pip install -r requirements.txt
```

## Автоматическая сборка

При каждом push, pull request или запуске вручную GitHub Actions собирает готовые версии для Windows и Linux. Архивы доступны во вкладке **Actions → Build SoundBoard → Artifacts**.

Чтобы создать GitHub Release с прикреплёнными архивами, создайте и отправьте тег вида `v1.0.0`:

```bash
git tag v1.0.0
git push origin v1.0.0
```

В готовой сборке звуковые файлы находятся в папке `sounds` рядом с программой. Можно заменить их своими файлами или передать другой каталог первым аргументом.

## Запуск

### Вариант 1 — положите скрипт в папку со звуками

```bash
cd /папка/со/звуками
python soundboard.py
```

### Вариант 2 — укажите папку через аргумент

```bash
python soundboard.py /путь/к/папке/со/звуками
```

## Поддерживаемые форматы

`.mp3` `.wav` `.ogg` `.flac` `.mid` `.midi` `.opus` `.aiff` `.aif` `.wma` `.m4a`

## Интерфейс

| Элемент | Описание |
|---|---|
| **Вероятность** | Числитель / Знаменатель (например 1 / 100000) |
| **Громкость** | Общая громкость всех звуков (0–100%) |
| **Интервал** | Сколько секунд между проверками |
| **▶ Запустить / ⏹ Остановить** | Включить / выключить генерацию |
| **🔊 Тест** | Воспроизвести случайный звук прямо сейчас |
| **🔄 Обновить** | Пересканировать папку на наличие новых звуков |
| **☑ Все / ☐ Никакие** | Включить / выключить все звуки разом |
| **Чекбокс** | Включить / выключить конкретный звук |
| **Слайдер громкости** | Индивидуальная громкость каждого звука |
| **▶ в строке** | Воспроизвести только этот звук |
| **×N** | Сколько раз этот звук был воспроизведён |
